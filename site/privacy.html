Privacy

Last updated 17 October 2026

Session Board is a free, open-source Claude Code mod and window app by Kiran Pothana. It runs on your computer. This page says what it reads, what it keeps, and what it sends, and where. Its code is public: github.com/KiranPothana/session-board.

What it reads

Files Claude Code already writes on your computer: its list of running sessions, and the saved conversations of those sessions. It reads them to show what each session is doing.

On a Mac, with the Accessibility permission, the Claude Desktop window: which session it has open (for the highlight), the names and status of the sessions in its sidebar, and the latest exchanges of a cloud session's chat while you have it open there (for cloud sessions, which leave nothing else on your computer). It also reads the session names Claude Desktop keeps on your computer, to tell its own sessions from cloud ones. None of this leaves your computer, except a cloud chat's exchanges, which are summarized the same way as any session's (below) unless summaries are off; they're kept in Session Board's folder for a week at most.

What it keeps, and where

  • A short record for each session (its status, its requests cut to a line each, task list and summary), in Claude Code's plugin store on your computer. It's deleted when the session ends.
  • Your window settings, the lines you removed, and your own sounds, in Session Board's folder on your computer.

Nothing is kept anywhere else, apart from bug reports you choose to send (below).

What it sends, and where

  • Summaries: the last few requests and replies of a session (for a cloud session, those Claude Desktop last showed), and its earlier requests cut to a line each, go to Claude through Claude Code's own model call, on your Claude account, the same way the session itself talks to Claude. Anthropic's terms and privacy policy apply to that. You can turn summaries off in Settings.
  • Bug reports, only when you ask (you say "report", or click Report or a Feedback button): your description, the versions of Session Board, Claude Code and your system, the window's settings, how many sessions are on the board, Session Board's error messages and a crash's stack trace. Your home folder and user name are removed, and nothing from your chats is included. With the GitHub CLI signed in, the report becomes a public issue on the GitHub repo, under your account. Otherwise it goes to Session Board's report inbox, a Cloudflare Worker that files it as an issue in a private GitHub repo only the maintainer can read; the inbox itself keeps nothing.
  • Downloads (Windows and Linux): the window app is downloaded from the GitHub repo's releases, which GitHub sees as a download.

There are no analytics, no tracking and no ads, in the app or on this website.

How long reports are kept

A report stays as a GitHub issue until it's deleted. To have one deleted, ask on GitHub issues (for a private report, give its report number) and it will be.

This website

sessionboard.dev is a static page hosted on GitHub Pages. It sets no cookies and loads nothing from other services. GitHub may log visits as part of hosting it; see GitHub's privacy statement.

Children

Session Board is a developer tool, not meant for anyone under 18.

Changes and contact

Changes to this page are made in the public repo, so its history shows every one. Questions: GitHub issues.
